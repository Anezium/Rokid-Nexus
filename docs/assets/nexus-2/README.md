# Nexus 2.0 site media

These are optimized exports of the approved release-demo captures, collected in
the local `build/Nexus-2.0-Reddit-ready` publication folder. Glasses images show
the actual glasses display; phone images show the phone settings. The chat is a
demo conversation, and the navigation position is simulated. No additional map
blur or large screen mask is added.

The launcher card, opened route page and floating home map are separate views.
The root Navigation card contains text guidance; its embedded map appears after
opening the card. Map data is credited in the captures to OpenStreetMap.

`nexus-2.0-montage.mp4` is the final 96.5-second V5 edit, H.264/yuv420p at
1080×1350, without audio. Its encoding frame rate is not a device-performance
measurement. `tour-captions.vtt` and `tour-transcript.txt` describe its chapters.
`og-nexus-2.jpg` combines the real launcher and route-page captures for link previews.

The Pages workflow copies this directory to `site/assets/nexus-2/` alongside
the existing documentation images. The source recordings and QA contact sheets
remain local and are not part of the site artifact.
